# 📝 Notes Application

A sleek, responsive, and high-performance Note-Taking application built with **React**. This project focuses on clean UI/UX, efficient state management, and seamless CRUD operations.

---

## 🚀 Live Demo
Check out the deployed application here:  
👉 [Notes App Live Link](https://notes-application-8vpq.vercel.app/)

---

## ✨ Features

- **Full CRUD Functionality:** Create, Read, Update, and Delete notes instantly.
- **Authentication:** Proper authentication is provided using next-auth.
- **Responsive Design:** Optimized for Mobile, Tablet, and Desktop views.
- **Search & Filter:** Quickly find your notes.
- **Interactive UI:** Smooth transitions and modern card-based layout using **Lucide-react** icons.
- **Auto-save Simulation:** Ensuring your data stays consistent throughout your session.

---

## 🛠️ Tech Stack

- **Frontend:** React.js/Next.js
- **Styling:** CSS3 / Modern Flexbox & Grid
- **Icons:** Lucide-react
- **Deployment:** Vercel
